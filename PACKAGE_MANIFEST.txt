The sitemap URL remains https://www.reconbrief.in/sitemap.xml. www is the preferred host because production redirects non-www requests to www. The generator updates public/sitemap.xml and dist/sitemap.xml during npm run build. Inactive root-level sitemap.xml and robots.txt duplicates were removed; the public files are the authoritative crawler configuration.

Root HTML page entries are discovered automatically by Vite. index.html.html and common private, test, preview, draft, redirect, and error-page filenames are excluded. The sitemap further requires a self-canonical HTTPS URL on www.reconbrief.in, excludes noindex pages and private/test routes, and requires the canonical path to match the built HTML route.
